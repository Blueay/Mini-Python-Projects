# 🔐 MyPass - Password Manager

![Python](https://img.shields.io/badge/Python-3.x-blue?logo=python&logoColor=white)
![Tkinter](https://img.shields.io/badge/GUI-Tkinter-red)
![Status](https://img.shields.io/badge/Status-Completed-success)

A simple desktop **Password Manager** built with **Python** and **Tkinter**.

The application allows users to generate strong random passwords, store website credentials locally, and automatically copy newly generated passwords to the clipboard for quick use.

# 🚀 Features

- 🔑 Generate secure random passwords
- 🎲 Random letters, numbers, and symbols
- 📋 Automatically copy passwords to the clipboard
- 💾 Save credentials locally
- 🌐 Store website, email, and password
- ✅ Confirmation dialog before saving
- ⚠ Input validation for empty fields
- 🖥 Clean Tkinter graphical interface

# ▶️ How to Run

Clone the repository:

```bash
git clone https://github.com/yourusername/python-mini-projects.git
```

Navigate into the project folder:

```bash
cd Password-Manager
```

Install the required package:

```bash
pip install pyperclip
```

Run the application:

```bash
python main.py
```
